# VoxPaint — Initial Chat Summary

## 1. Product Vision

VoxPaint is a greenfield web app for low-poly 3D model creation. "Voxel plus" modeler — supports cubic voxels and 45° chamfered voxels, authored through a 2D pixel-art editor. The 3D view is a live preview and navigation tool (pick which slice to edit), not the primary drawing surface.

## 2. Key Design Decisions

### Chamfer System — 3-Piece Autotile
- Not a generic bevel tool. At paint time, checks 8-neighborhood in chamfer layer.
- **Ramp**: 3/4 orthogonal neighbors filled → slopes down toward empty side.
- **Convex corner**: 2 adjacent orthogonal filled (L-shape) → slopes on both open sides, diagonal ridge.
- **Concave corner**: all 4 orthogonal filled, exactly one diagonal empty → notched at that diagonal.
- Invalid configurations are blocked from painting (no fallback).
- Chamfer is baked at paint time; editing neighbors never reclassifies existing cells.
- Chamfer paint always also writes the color layer.

### Construction Plane
- Defined by `{ axis: x|y|z, orientation: +1|-1, offset: integer }`.
- Set via 3D gizmo caps or clicking a voxel face in 3D (face normal → axis+orientation, offset = clicked cell's coordinate).
- Cyclic (u,v) basis per axis: x→(y,z), y→(z,x), z→(x,y).

### Stack
- Vite + React + TypeScript + Zustand + Immer
- Tailwind CSS, Radix UI, lucide-react
- Three.js + @react-three/fiber + @react-three/drei
- three-bvh-csg for GLTF export
- Dark-mode only, desktop first (touch/mobile deferred to future phase)

### Grid & Limits
- Sparse maps (color + chamfer layers), keyed by CellKey string.
- Hard-enforced 64×64×64 bounding box.

### Undo/Redo
- Atomic whole-model snapshots via Immer structural sharing, one per completed gesture.
- 100-step cap, does not persist across reload.

### Persistence
- Unified JSON schema (schemaVersion, palette, colorCells, chamferCells) for localStorage autosave AND explicit export/import.
- Migration registry from day one.
- GLTF export via CSG union + vertex weld (Web Worker, with progress).

### Palette
- 28 slots: 16 base + 4 emissive + 4 blink + 4 pulse.
- Indexed-palette behavior (cells store slot ref, not resolved color).
- Blink = square wave, pulse = sine, both GPU-driven via shared ShaderMaterial with uClock uniform.

### 3D Rendering
- 4 InstancedMesh pools (cube, ramp, convex, concave).
- InstancingManager handles dense arrays + diff-based dirty range updates (no React re-renders on paint).
- Shared custom ShaderMaterial extends MeshStandardMaterial for emissive/blink/pulse.

## 3. Architecture

### Engine Modules (framework-agnostic, unit-testable)
- `engine/grid/` — sparse maps, bounds tracking, key encoding
- `engine/plane/` — construction plane math, plane↔grid mapping
- `engine/chamfer/` — neighbor sampling, classification, validation, mesh geometry
- `engine/instancing/` — InstancingManager, shared material, instance transform basis
- `engine/csg/` — CSG union/weld/bake/GLTF export pipeline
- `engine/persistence/` — schema, serialize, migrations, autosave, project file I/O
- `engine/tools/` — line utils (Bresenham, ortho snap), tool modules sharing Tool interface

### Zustand Store Slices
- `project` — model + palette (Immer + persistent-map)
- `history` — undo/redo stacks
- `tool` — active tool, layer, palette slot
- `plane` — construction plane state
- `selection` — region + clipboard
- `view` — fullscreen, hover state (ephemeral)
- `persistence` — autosave/dirty/error state
- `paintActions` — paintColorCell, paintChamferCell (with validation), eraseCell

### React Components
- `MainLayout` → TopToolbar, LeftPanel (tool palette), CenterSplit (Editor2D + Viewport3D), RightPanel (layer toggle, palette, stats)
- `PixelCanvas` — 2D canvas editor, CELL_PX=12, tools routed through Zustand
- `Viewport3D` — R3F Canvas with OrbitControls, SceneLighting, ConstructionPlaneGizmo, VoxelInstancedMeshes
- Toast system via Radix primitives + simple pub/sub bus

## 4. Scaffolding Outcome

Created full project scaffold with Vite + React + TS. Wrote all engine modules, store slices, and React components. TypeScript typecheck passes cleanly. Build succeeds. Dev server runs. Browser screenshots verified rendering.

## 5. Out of Scope for v1
- Touch/stylus input and mobile layout
- Coplanar-quad mesh simplification (beyond CSG union + vertex weld)
- Cross-session undo history persistence
